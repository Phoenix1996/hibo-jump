# 海宝跳跳

一个纯前端的图案归列小游戏，使用原生 HTML、CSS 和 JavaScript，不需要安装依赖或构建步骤。

## 开始游玩

直接打开 `index.html`，或用任意静态文件服务器提供当前目录。默认进入困难模式：7 种图案、8 列、每列最多 12 格、8 个暂存位、1000 步反向打乱，并包含隐藏图案与分散的固定白格。

游戏进度、三个存档、难度设置、主题选择和音效开关保存在当前浏览器。更换设备或浏览器不会自动同步存档。

## 游戏规则

- 列与列之间自动移动顶部连续同图案，目标列剩余空间决定移动数量。
- 只能把图案放入空列，或放到顶部相同图案上；固定白格没有图案、不能移动，会分散在不同列底部。它们各自代表所在列少一个同色图案；一列填满且其余图案同色时，白格不影响完成判定。
- 完成列会锁定，不能再移出或接收图案；界面不显示已完成列数。
- 打乱从已完成棋盘反向生成，保留可解路径；后退会撤销上一步。
- 打乱按单个图案逐步混合，并避开最近的反向重复；同组移动时图案逐个飞行，问号格逐个翻开。
- 海洋、水果、宝可梦、宝可梦徽章和数码宝贝是独立主题，规则与存档进度不变。

## 发布

推送到 `main` 分支会触发 `.github/workflows/pages.yml`，通过 GitHub Pages 发布整个静态项目。图案资源存放在 `assets/themes/`。
