# 海宝跳跳

一个纯前端的图案归列小游戏，使用原生 HTML、CSS 和 JavaScript，不需要安装依赖或构建步骤。

## 开始游玩

直接打开 `index.html`，或用任意静态文件服务器提供当前目录。默认进入困难模式：7 种图案、8 列、每列最多 12 格、8 个暂存位、1600 步反向打乱，并包含隐藏图案与固定白格。生成时会把暂存位作为反向打乱缓冲区，把图案重新分配到不同列；出题时暂存区仍为空，且保留可还原到完成棋盘的合法路径。也可以从关卡入口开始每日挑战：同一日期使用同一棋盘，本地保留各日最佳步数、累计通关天数和连续通关天数。

游戏进度、三个存档、难度设置、主题选择和音效开关保存在当前浏览器。更换设备或浏览器不会自动同步存档。

## 手机上游玩

在 iPhone/iPad 的 Safari 打开游戏，点“分享”→“添加到主屏幕”，并启用“作为网页 App 打开”。以后从主屏图标启动会以独立窗口打开，不显示 Safari 地址栏。首次联网打开后，游戏页面和全部图案会缓存，断网时也能继续游玩。

## 游戏规则

- 列与列之间自动移动顶部连续同图案，目标列剩余空间决定移动数量；整组作为一个整体移动，并计为一步。
- 只能把图案放入空列，或放到顶部相同图案上。固定白格没有图案、不能移动，可能有多个出现在同一列底部，不强制分散到不同列。它们代表所在列少了该列的图案；一列填满且其余图案同色时，白格不影响完成判定。
- 完成列会锁定，不能再移出或接收图案；界面不显示已完成列数。
- 打乱从已完成棋盘反向生成，保留可解路径；候选棋盘会优先保留完成合法打乱步数更多的局面。后退会撤销上一步。
- 生成棋盘时按单个图案逐步混合并避开最近的反向重复。移动时整组图案连在一起飞行；问号格单独揭晓后才能和同图图案一起移动。
- 海洋、水果、宝可梦、宝可梦徽章和数码宝贝是独立主题，规则与存档进度不变。

## 发布

推送到 `main` 分支会触发 `.github/workflows/pages.yml`，通过 GitHub Pages 发布整个静态项目。图案资源存放在 `assets/themes/`。
